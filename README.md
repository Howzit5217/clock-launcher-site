# Clock Launcher

A beautiful, low-power desktop clock for Windows 10 and 11: 30 themes, living scenes, your own pictures,
alarms, a timer and a stopwatch.

**Get it:** https://howzit5217.github.io/clock-launcher-site/

Or download **ClockLauncher.exe** from [Releases](https://github.com/Howzit5217/clock-launcher-site/releases/latest)
and run it. After that it updates itself: every few hours it checks this repository's latest release and puts in a
newer one while the clock isn't being used (or when you click Update; *Settings > Help & about* to choose).

This repository holds the download page and the releases. The only thing the app ever fetches is its own updates.
